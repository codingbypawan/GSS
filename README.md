# Gurukul Shikshan Sansthan — School Website

A modern, premium, responsive website for **Gurukul Shikshan Sansthan**, Khampar (Jaipur), Deoria, Uttar Pradesh, India.

## Features

- **Config-driven** — All school content managed from a single `js/config.js` file
- **Fully responsive** — Works on desktop, tablet, and mobile
- **Premium design** — Deep Blue & Gold color palette with glassmorphism cards
- **Animated sections** — Scroll reveal, animated counters, lightbox gallery
- **Admission banner** — Configurable floating admission banner with bounce animation
- **WhatsApp integration** — Floating WhatsApp button for instant contact
- **Login redirect** — Redirects to the school management portal

## Tech Stack

- HTML5
- TailwindCSS (CDN)
- Vanilla JavaScript
- FontAwesome 6.5.1
- Google Fonts (Inter)

## Project Structure

```
GSS/
├── index.html        # Main website
├── login.html        # Login redirect page
├── logo.png          # School logo (transparent background)
├── css/
│   └── style.css     # Custom styles & animations
└── js/
    ├── config.js     # Central configuration (edit this to update content)
    └── main.js       # Dynamic rendering & interactivity
```

## Configuration

Edit `js/config.js` to update:

- School name, tagline, contact details
- Facilities, academics, and "Why Choose Us" cards
- Gallery images, counter values
- Admission banner text and visibility
- Social media links
